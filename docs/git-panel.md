# Git 面板

点击状态栏分支名打开 Git 面板。面板随当前终端目录更新；未打开终端时使用选中项目目录。切换目录后，旧请求结果不会覆盖新仓库状态。应用重新激活、手动刷新和 Git 操作完成后都会更新状态。

## 状态与文件

- **获取**：获取所有远程仓库更新并清理失效的远程跟踪引用。
- **拉取**：仅允许 fast-forward，需要已设置 upstream。
- **推送**：有 upstream 时正常推送；只有一个远程且尚未设置 upstream 时，首次推送自动建立跟踪关系。多个远程但没有 upstream 时，需要先在终端设置跟踪分支。
- 支持逐文件或全部暂存、取消暂存，包括尚未产生首次提交的仓库。
- 同一文件同时存在暂存和未暂存改动时，`Δ` 查看暂存差异，`W` 查看未暂存差异；`+` 暂存后续改动，`−` 取消暂存。
- **放弃未暂存**需要确认：已暂存内容保留，未暂存的已跟踪内容还原到暂存区，未跟踪文件和目录会删除。冲突文件需要先在终端或编辑器处理。
- 中文、空格、引号、换行和包含 ` -> ` 的路径使用 Git 的 NUL 分隔格式解析，重命名取消暂存会同时处理新旧路径。
- 提交失败保留提交信息；成功才清空。存在未解决冲突时禁用提交。

## 分支与工作树

- 区分本地、远程分支，忽略远程 HEAD 符号引用。切换远程分支时优先复用已有跟踪分支，否则创建同名本地分支；若名称已被其他分支占用，显示 Git 错误并保留现有分支。
- 添加工作树：分支栏为空时使用 Git 默认行为；填写已有本地分支时检出它，填写新分支名时创建新分支。
- **打开**将工作树加入侧边栏并在该目录打开会话。
- **移除**需要确认，保留分支，不使用 `--force`。Git 会拒绝删除包含未提交内容、未跟踪文件或锁定状态的工作树。当前工作树禁用移除。
- 操作失败显示错误，保留新分支名和工作树输入；命令组合中任一步失败，后续命令不会执行。

## 开发验证

Git 数据模型和进程调用位于 `Sources/ClaudeDeck/Git.swift`；UI 与异步请求状态在 `main.swift`。

```bash
swift build
bash scripts/test-git.sh
```

回归脚本在临时目录创建本地仓库和 bare 远程，验证文件状态解析、重命名、暂存、首次推送、跟踪分支、工作树保护、detached HEAD、冲突分类以及大 diff 管道读取。它不会操作项目仓库的索引，也不会连接外部远程。系统需提供 Swift 6 和 Git。
