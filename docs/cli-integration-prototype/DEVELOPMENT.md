# 多 CLI 接入与工作区交互开发方案

本方案汇总 2026-11-19 的原型与批注。来源为 Codex 会话 `01a1f1a6-2874-71c1-942f-0594ad8f0ad9`，界面与 Git 基线为 test 分支 `63a3bbc`。原型中的 Git、CLI、TAPD 认证、额度和回合事件为演示数据。下文记录正式接入目标，开发分支的实际实现见末尾。

## 1. CLI 引擎和会话

### 设置与新建

- 在「设置 → CLI 引擎」集中管理全局打开方式、新会话权限、提示缓存计时器、已安装和可安装引擎。已安装行显示图标、命令、可用状态、启停及默认引擎标记，支持刷新。支持聊天的引擎可以跟随全局或单独选聊天／CLI。权限同样可以按引擎覆盖。「可安装」展示候选引擎及已有的安装说明。WorkBuddy 仅在这里登记，独立 CLI 入口仍待验证。
- 保留 Claude Code 和 Antigravity，新增独立的 Codex CLI 和 DeepSeek Harness（dsh-TUI）入口。默认引擎只预选新会话的引擎。停用后禁止新建或重新打开该引擎的会话，历史仍可见。停用默认引擎时，原型会切到下一个可用引擎。
- 在项目右键「新建对话」或通过快捷键创建会话。表单选择 CLI、可选会话名与当前分支／独立工作树。DeepSeek 要同时检测 `dsh-tui` 和 `dsh`。缺少 `dsh` 时保留恢复目标和工作目录，指向依赖说明，重新检测通过后继续。DeepSeek 终端显式使用 `--backend dsh`。
- 启动检测区分命令缺失、依赖缺失、未登录、已停用和协议能力不足。桌面端需处理 GUI 的 PATH、用户指定的命令位置、含空格路径和系统差异。打开历史时使用记录中的 CLI、原始会话 ID 与执行目录。

| 引擎 | 终端入口 | 结构化聊天接入方向 | 历史与恢复的验证重点 |
| --- | --- | --- | --- |
| Claude Code | `claude` / `claude --resume <id>` | 复用现有 `ClaudeExecutor` 的 `stream-json` | 现有扫描与旧会话恢复回归 |
| Codex CLI | `codex` / `codex resume <id>` | `codex app-server`，按版本验证线程、回合、流式事件、审批和中断 | `thread/list` 分页、原始线程 ID、项目目录 |
| Antigravity | `agy` / `agy --conversation <id>` | 验证 `agy acp` 的初始化、恢复、流式输出和审批 | 保留 test 版历史路径；验证 ACP 会话与 CLI 历史的关联 |
| DeepSeek Harness | `dsh-tui --backend dsh` / `dsh-tui --backend dsh --resume <id>` | 原型使用终端。结构化能力待评估 | 验证 `dst session list --json` 和 `session show` 与 TUI profile 的会话 ID 可互相恢复 |

参考 [Codex App Server](https://learn.chatgpt.com/docs/app-server#api-overview) 和 [dsh-TUI 自动化 CLI](https://github.com/ccch1mneyyy/dsh-TUI/blob/HEAD/docs/cli.en.md)。

### 聊天与终端

- 沿用 test 版原生终端路径，macOS 使用 SwiftTerm，Windows 使用现有 Electron PTY。结构化聊天在同一会话位置展示 Markdown、流式回复、可折叠工具记录、等待审批和中断。消息区独立滚动，输入框固定在底部。用户向上阅读时保持位置，可跳到最新。审批通过或拒绝后保留结果。
- 打开方式保存在会话上。全局设置与引擎覆盖只决定新会话的初始界面。用户可从当前会话切换，运行中或等待审批时先结束当前回合。DeepSeek 和缺少结构化能力的执行环境走终端。
- 正式运行时，同一原始会话只能有一个写入者。切换前确认另一端已释放会话权，失败时保留原界面。关闭视图、重新挂接仍在运行的进程、按原始 ID 恢复历史应有独立结果。原型支持会话内切换，跨 App 重启需验证真实协议和持久化。
- Orca 参考实现具有独立消息滚动区、固定输入区与原始会话恢复。历史菜单中的「在新 CLI 中恢复」存在 fork 语义，ClaudePicker 是否沿用见待拍板事项。会话恢复的交互参考 [Orca Native Chat](https://orca.dev/docs/agents/native-chat)。

### 提示缓存计时器

在 CLI 设置提供开关和 TTL，默认 5 分钟，原型可选 5、10、15、30、60 分钟。Claude 会话结束一轮并空闲后，在对应会话行显示估算倒计时。运行或等待期间、到期后、关闭开关时隐藏。原型以成功回合完成时间为起点。正式版需确定缓存起点依据、跨重启恢复行为和覆盖范围。

## 2. 项目树、工作树与 Diff

### 归属和创建

- 第一栏采用「项目 → 分支／工作树 → 会话」。移除原有按引擎筛选条。分支和工作树可折叠，一个节点包含多个会话。各平台标识在会话行显示，Codex 原型采用 OpenAI 品牌图标。拖拽在同一分组内重排，跨分组不改写会话归属。
- 会话记录至少包含应用会话 ID、CLI 类型、CLI 原始 ID、项目、执行位置、工作目录、绑定分支、工作树路径和打开方式。独立工作树按实际目录区分，普通会话按绑定分支分组。新建时记录实际执行位置，切换 Git 分支时不批量更新既有会话。缺少归属证据的历史归入「未绑定分支」。
- 从「工作树」页或项目右键打开「创建工作树」。表单选项目、运行位置、起始分支、名称和可选代理。原型只提供本地 Mac，优先默认 `origin/main`，不可用时选当前分支。工作区名称生成新分支和目录并预览。重名或无效来源要显示错误并保留表单。选「仅创建工作树」后项目树显示空节点，选代理则在新目录打开会话。
- 正式创建需区分创建工作树成功与启动代理成功。代理启动失败时保留已创建工作树并提供重试入口，避免重试创建同名分支。未创建成功时不登记会话。

### 右键切换和 Diff

- 分支／工作树右键提供「新建对话」「在工作区查看 Diff」「复制分支名」「复制工作目录」。从节点新建时，弹窗锁定对应分支和工作目录；在该目标中创建后打开会话。
- 会话右键提供「查看会话信息」「复制会话 ID」「复制恢复命令」。共享的是 CLI 原始 ID，并提供引擎、分支、路径和恢复命令，历史数据仍由原引擎和对应环境持有。原始 ID 未获取时停用复制 ID 和恢复命令。
- 「变更」页把项目选择与分支选择拆开。分支面板内搜索本地和远程分支，点击或按 Enter 切换，方向键移动，Escape 关闭。
- 在分支／工作树右键选「在工作区查看 Diff」。独立工作树直接读取对应目录，普通分支走切换分支流程。目标就绪后收起第二栏并展开第三栏，选中「工作区 → 差异」。此操作仅改变视图和 Git 上下文，终端进程生命周期仍由原有运行层管理。切换失败时保留原布局和目标，提示原因。
- Git 状态、选中文件、差异、预览、编辑和暂存请求必须绑定同一执行目录。切到其他工作树时清理旧文件选择并拒绝旧异步结果。普通分支遇到未提交改动的处理见待拍板事项。
- Diff 默认并排，可切换统一视图。未暂存显示「暂存区／工作区」，已暂存显示「HEAD／暂存区」。并排行按变更块垂直对齐，中间色带关联变化，新建或删除时对侧保留空位，成对修改突出行内文本差异。
- 通过上一处／下一处或在 Diff 聚焦后使用 `Shift+F7`／`F7` 跳转。变更块数量与当前位置可见，首尾禁用对应按钮。切换文件后重置当前位置。保留暂存、取消暂存、预览与编辑入口。二进制、无文本差异、加载失败与截断分别显示提示。 [JetBrains Diff Viewer](https://www.jetbrains.com/help/idea/comparing-file-versions.html)

## 3. 第一栏额度与设置入口

- 「使用额度」放在第一栏「添加目录」下方。设置齿轮位于「收起侧边栏」左侧。
- 入口、弹层和详情页共用配色、图标尺寸、进度条和百分比排版。「已用／剩余」统一换算可比较的额度。「详细／精简」调整展示的时间窗口和说明，数值来源不受影响。引擎行支持展开各窗口和重置时间，底部有使用详情与历史、管理账户入口。刷新反馈更新时间或失败。
- 当前原型展示 Codex、Claude、Antigravity；Codex 和 Claude 展示短窗口与周窗口，Antigravity 按模型组展示。正式数据应带引擎、账户、窗口、百分比或原始用量、重置时间与抓取时间。未登录、接口不可用或缺少某个窗口时显示对应状态，不能用 0% 代替。DeepSeek 未确定可读额度口径。

## 4. TAPD MCP 配置与接入

- 「设置 → TAPD 连接」默认使用 MCP。正式本轮方案移除 TAPD CLI 路径设置与运行依赖。配置页写清服务地址的获取方式、项目 ID 来源、授权方式和所需访问权限。原型提供 OAuth 和服务访问令牌两种选择，正式支持组合需结合实际 MCP 服务确认。
- 「一键配置」读取待配置的 MCP 地址、授权方式和一个或多个项目 ID。多个 ID 支持换行、逗号或空格分隔，先去重。依次建立应用自己的连接，完成授权，执行 MCP 握手和工具发现，再按项目 ID 用项目元数据与待办的限量只读查询逐个验证。全部通过后保存配置，在 MCP 服务列表登记 TAPD，默认启用新项目。后续追加复用同一连接与授权，已配置项目保留启用状态和本地仓库映射。失败时说明阶段和可重试操作，保留原有可用配置。令牌由桌面安全存储接管，设置文件和日志只记录凭据引用。
- 配置成功后可重新检测，并在 TAPD 项目设置启用待办与登记本地仓库映射。读取可见字段、状态、评论等能力由实际工具能力与项目权限决定。配置与验证本身只读取，已有回填交互仍需预览和用户确认，不触发自动接单。
- 已确认当前 Codex 环境的 TAPD MCP 提供 `get_workspace_info` 和 `get_todo`，都能使用指定项目 ID 做试读。桌面端服务地址、认证、工具兼容性和真实测试项目仍需核实。原型「填入演示配置」使用示例地址，仅验证表单、连接状态和项目启用的变化。 [既有 TAPD 融合方案](../swttch-integration/TAPD融合方案.md)

## 8. 开发分支实现

`codex/wt-20261119` 当前以 macOS 本机为验证目标。

- 项目栏按真实分支或 Git 登记的工作树分组。缺少可靠归属的历史会话归入「未绑定分支」。会话菜单显示引擎、绑定分支、工作目录、原始 ID 和恢复命令。
- 工作树独立创建，默认仅创建，优先从 `origin/main` 分支起步。代理启动失败可在已创建的目录中重试。工作树节点可直接进入对应目录的 Diff。普通分支需要切换且主工作区有未提交改动时，保留原位置并提示处理。
- 工作区差异默认并排，保留统一查看、暂存、预览与编辑。工作树切换时重新载入状态和文件。差异导航可使用 F7 或 Shift+F7。
- macOS 提供 Claude、Antigravity、Codex 和 DeepSeek 终端入口。Codex 从本地 rollout 元数据读取历史，DeepSeek 读取 dsh-TUI 索引与 DSH 元数据缓存的交集。深度恢复依赖对应 CLI 版本和原 profile。没有可靠的原始 ID 时保留待绑定状态，禁止复制不存在的恢复命令。
- CLI 设置集中放置默认引擎、引擎启用状态和缓存倒计时。倒计时根据 Claude JSONL 尾部可识别的完成事件估算。额度面板显示 Claude 与 Codex 的实际窗口，Codex 通过 CLI 的 `account/rateLimits/read` 获取。Antigravity 额度来源仍待确认。
- WorkBuddy 仅在 CLI 引擎目录中登记，移除企微设置中的接入说明。企微多机器人、授权范围、续聊与决策卡仍按独立开发方案推进。

- 打开方式按会话保存，取值终端、结构化聊天、Swttch 三种并存（D2 本轮按「两者并存」实现）。结构化聊天覆盖 Claude、Antigravity、Codex，DeepSeek 只走终端。同一原始 ID 由 `SessionOwnership` 保证单写者：切换前中断进行中的回合并等待执行器退出，Swttch 无单会话释放接口，切出时停止整个图形服务。
- TAPD 默认按 MCP 一键配置接入，桌面端实际形态是 `uvx` 启动的官方 `mcp-server-tapd`（stdio + `TAPD_ACCESS_TOKEN`），不是 HTTPS 服务。tapd-cli 仍用于按编号查询、「已创建」、详情、评论与状态流转。
- Windows 版接入四个引擎的终端启动与恢复，扫描 Codex 与 DeepSeek 历史；Antigravity 历史与聊天方式未适配。

- 结构化聊天输入框参照 Claude Code / Codex 桌面端：打开方式、权限模式、「模型 · 推理强度」合并选择器，⌘⇧M / ⌘⇧I / ⌘⇧E 打开菜单；发送键旁有上下文占用环；终端右上角关闭按钮旁可在终端与结构化聊天间切换。各引擎可切换的项与生效时机：

| 引擎 | 权限 / 模式 | 模型 | 推理强度 | 生效 |
| --- | --- | --- | --- | --- |
| Claude Code | 自动 / 手动 / 接受编辑 / 规划 | Opus / Sonnet / Haiku / Fable | 默认 / 低 / 高 / 极高 / 最高 | 模式与模型即时（控制请求）；推理强度空闲时按原 ID 重启 |
| Antigravity | ACP 报告的模式（手动 / 接受编辑 / 自动 / 规划） | ACP 报告的模型（强度体现在模型名里） | — | 即时（`session/set_mode`、`session/set_model`） |
| Codex | 请求批准 / 替我批准 / 完全访问 | `model/list` | 所选模型支持的档位 | 下一回合起（`turn/start` 覆盖） |
| DeepSeek | 只走终端 | — | — | — |

- DeepSeek Harness 启动时与每 6 小时只读巡检，有新版本或环境问题时提示升级；「可安装」目录新增 Qoder CLI（官方安装脚本，白名单执行）。
- 引擎相关界面统一使用各平台官方图标。
