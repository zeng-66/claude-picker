# Clawd 桌宠开发说明

## 当前原型

H5 v003 采用用户提供的 `clawd-resources/codex-pets/gifs` 动画素材。角色为戴耳机的像素 Clawd，默认显示、标准尺寸 128 × 139，背景透明。

桌宠作为页面浮层展示。点击打开当前会话状态气泡，拖动调整位置，右键打开动作菜单。黄色窗口按钮与设置中的「预览桌面模式」进入浏览器内的桌面演示。

状态气泡显示状态、当前会话名称，以及「打开会话」「悬浮输入」入口。打开会话时恢复工作空间的第二栏。悬浮输入入口展开已有浮窗，复用当前会话的输入与演示输出。

原型地址为 <http://127.0.0.1:5201/>，启动命令为 `./docs/desktop-release-prototype/v003/preview.sh`。

## 动作与状态

| 场景 | 动画 | 显示 |
| --- | --- | --- |
| 空闲 | `clawd-idle.gif` | 准备就绪 |
| 当前会话执行中 | `clawd-running.gif` | 正在执行 |
| 等待用户回答 | `clawd-waiting.gif` | 需要你的回答及提示标记 |
| 待审阅 | `clawd-review.gif` | 有结果待审阅及提示标记 |
| 执行失败 | `clawd-failed.gif` | 执行遇到问题及感叹号 |
| 已完成 | `clawd-jumping.gif` | 任务已完成及勾选标记 |
| 拖动或散步 | `clawd-running-left.gif` / `clawd-running-right.gif` | 与移动方向对应的动作 |
| 菜单「挥手」 | `clawd-waving.gif` | 临时挥手后回到当前状态 |
| 双击或菜单「跳一下」 | `clawd-jumping.gif` | 临时跳跃后回到当前状态 |

「跟随当前会话」使用原型 `active.busy` 展示空闲与执行中。设置中的演示状态可切换等待、审阅、失败和完成，以便批注。实际任务状态接入规划见下文。

## 交互

- 点击角色切换状态气泡，点击页面其它区域关闭气泡或菜单。
- 拖动超过 5 像素后移动角色，拖动结束播放一次跳跃反馈。
- 右键菜单提供打开会话、打开悬浮输入、挥手、跳跃、桌面模式、桌宠设置和隐藏桌宠。
- 设置提供显示开关、小 / 标准 / 大三档尺寸、空闲散步开关和演示状态。
- 空闲散步默认关闭。开启后每 10 秒向屏幕中部移动约 100 像素，使用对应方向的奔跑动画。
- 显示设置和位置保存在 `cp.h5-v003.desktopPet`、`cp.h5-v003.petPosition`，刷新后恢复。
- 位置按视口边界收敛，顶部预留标题栏、底部预留批注入口空间。

桌面模式隐藏页面内的主窗口标题栏与内容区，显示桌面背景、返回 ClaudePicker 按钮、桌宠和可交互的悬浮输入。点击「返回 ClaudePicker」或气泡内的「打开会话」可恢复主界面。

## 素材来源

9 个 GIF 均为 192 × 208 透明画布，按原比例展示。原文件复制到 `src/assets/clawd/`，来源路径、字节摘要与作者信息见 [SOURCES.json](src/assets/clawd/SOURCES.json)。逐个文件的 SHA-256 已与用户提供的素材核对。

用户素材目录的说明将此包标注为 Han1 制作、从官方 Claude Code Clawd 帧提取的社区桌宠包。Clawd 美术来源为 Anthropic。来源页面为 [Codex Pets Clawd](https://codex-pets.net/#/pets/clawd)。

## 后续原生接入设计

### 窗口与平台

macOS 使用透明、无边框的 `NSPanel` 承载桌宠，设置浮动层级、隐藏窗口标题栏，并将可见屏幕坐标转换为浏览器视口坐标。主窗口最小化后，桌宠窗口继续显示。主窗口与桌宠窗口复用同一应用运行时。

Windows 使用 Electron 的透明无边框 `BrowserWindow`，配置 `alwaysOnTop`、`skipTaskbar`，通过现有 preload / IPC 接口读取状态与打开会话。窗口内容仅包含桌宠及气泡，主窗口可单独显示或最小化。

两个平台都需要验证透明区域的鼠标穿透、拖动命中区域、多显示器可用边界、显示器缩放和全屏空间行为。位置持久化记录所属显示器，显示器断开时回退到主屏可见区域。

### 状态与会话路由

主进程汇总普通会话与 Work 的实际状态，按等待回答、失败、待审阅、执行中、完成和空闲的顺序选择需要展示的状态，并携带对应的 `sessionId` 或 Work 标识。点击气泡时打开该状态对应的会话或 Work 详情。

普通会话复用现有 App 状态事件。Work 事件通过现有 Work 快照和变更通知汇总。桌宠与悬浮输入共用当前会话标识、输入状态和终端输出，跨窗口展示时由同一执行实例提供数据。

原生设置可沿用显示、尺寸和空闲散步三个字段。原型演示状态选择器用于交互评审。实际 App 的状态由会话与任务事件驱动。

### 验收入口

1. 运行任务时展示执行动画，进入等待、审阅、失败与完成状态时切换对应动作。
2. 点击气泡能定位到产生状态的会话或 Work。
3. 主窗口最小化后桌宠继续显示，可从桌宠恢复主窗口或打开悬浮输入。
4. 拖动、透明命中、窗口置顶、多显示器与显示缩放经桌面实际操作验证。
5. 退出应用后关闭桌宠窗口，重新启动恢复显示偏好和可见位置。

## 本轮验证记录

已通过 Vite 构建，并在浏览器验证桌宠素材加载、透明背景、点击状态气泡、右键设置入口、等待和失败状态动画、显示开关、尺寸切换、拖动、挥手、空闲散步、位置刷新恢复、桌面模式，以及恢复当前会话与悬浮输入。

浏览器开发日志检查无错误。当前桌面模式的运行环境为 H5，原生窗口与实际任务事件列于后续接入设计。
