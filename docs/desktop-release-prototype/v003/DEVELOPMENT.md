# v003 交互开发说明

本版承接 v002，并根据 [四处移除批注与桌宠需求](comments/2026-11-17-v003.md) 清理界面和增加 Clawd 桌宠。当前交付范围为 H5 原型及对应文档。来源提交和父版本摘要见 [SOURCE.json](SOURCE.json)。

## 运行

在项目根目录执行 `./docs/desktop-release-prototype/v003/preview.sh`，打开 <http://127.0.0.1:5201/>。

## 顶部页签与两栏布局

| 顶部页签 | 第一栏 | 第二栏 |
| --- | --- | --- |
| 工作空间 / 会话 | 项目与会话树、额度区、添加目录和设置 | 选中的会话终端及输入区 |
| TAPD 待办 | 全部项目、lm-global、蓝马 | 对应项目任务项，可搜索、按状态筛选并查看详情 |
| Work 中心 | 全部 Work、执行中、待回答、待审阅、已结束 | 对应 Work 看板或列表，可查看演示任务详情 |
| 变更 | 工作区、提交历史、分支、工作树、更多 | 对应 Git 工作台页面 |

工作空间沿用项目与会话树，并按本轮批注移除「我的待办」「Work 中心」两个侧栏快捷入口和侧栏执行队列。第二栏右侧的折叠工作台竖条已移除。TAPD、Work 和变更的操作栏通过 `ModuleSidebar` 渲染。

设置新增「顶部页签」。四个页签各自提供显示开关，拖动设置行或顶部图标即可调整顺序。设置行同时提供上移、下移按钮。拖动顶部图标只调整顺序，点击图标切换页面。隐藏当前页签时显示剩余顺序中的首个页签。全部隐藏时保留工作空间的第一栏与终端第二栏，不展示顶部页签，设置入口保持可达。

导航显示与顺序保存至原型浏览器存储，刷新后恢复。v002 的界面状态使用 `cp.h5-v003.*` 键。

## 悬浮终端

第二栏终端实际展开的条件为当前页签是工作空间，且 `settings.terminal` 为真。其它页面及终端收起时可从桌宠打开同一个悬浮终端，页签切换延续其位置、尺寸、最小化状态和当前会话输入。

- 拖动标题栏移动浮窗。收起后仅保留桌宠，点击桌宠直接恢复浮窗，桌宠继续显示。
- 右下角与左上角拖柄可连续缩放。聚焦拖柄后通过方向键每次调整 20 像素。
- 常规最小尺寸为 280 × 180。宽度达到 520 且高度达到 330 时显示终端演示内容。窄窗口按可用视口尺寸调整显示阈值。
- 标题栏提供展开 / 收起终端内容按钮，以及收起到桌宠和在工作空间展开终端按钮。
- 浮窗上限与位置约束按浏览器视口计算，底部预留批注入口空间。
- 从浮窗恢复第二栏时打开工作空间的会话视图。工作空间页签被隐藏时，此操作同时开启该页签。

浮窗和第二栏共享演示终端内容。输入通过当前原型的 mock 桥接发送，发送后的文本显示于当前会话的演示输出中。演示输出保存在本次页面会话内。TAPD 与 Work 的示例条目在页面上标注为演示数据。

2026-11-17：悬浮图标入口合并进桌宠，点击直接打开窗口，收起不再生成图标。桌面演示中桌宠持续显示且可在整个视口移动。全桌面悬浮的原生独立窗口契约见 DESKTOP_PET.md，当前 H5 未实现系统级悬浮。
