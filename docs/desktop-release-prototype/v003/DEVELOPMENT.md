# v003 交互开发说明

本版承接 v002，并根据 [四处移除批注与桌宠需求](comments/2026-11-17-v003.md) 清理界面和增加 Clawd 桌宠。当前交付范围为 H5 原型及对应文档。来源提交和父版本摘要见 [SOURCE.json](SOURCE.json)。

## 运行

在项目根目录执行 `./docs/desktop-release-prototype/v003/preview.sh`，打开 <http://127.0.0.1:5201/>。

## 顶部页签与两栏布局

| 顶部页签 | 第一栏 | 第二栏 |
| --- | --- | --- |
| 工作空间 / 会话 | 项目与会话树、额度区、添加目录和设置 | 选中的会话终端及输入区 |
| TAPD 待办 | 全部项目、lm-global、蓝马 | 对应项目任务项，可搜索、按状态筛选并查看详情 |
| Work 中心 | 全部 Work、执行中、待回答、待审阅、已结束 | 对应 Work 看板或列表，可查看演示任务详情 |
| 变更 | 工作区、提交历史、分支、工作树、更多 | 对应 Git 工作台页面 |

工作空间沿用项目与会话树，并按本轮批注移除「我的待办」「Work 中心」两个侧栏快捷入口和侧栏执行队列。第二栏右侧的折叠工作台竖条已移除。TAPD、Work 和变更的操作栏通过 `ModuleSidebar` 渲染。

设置新增「顶部页签」。四个页签各自提供显示开关，拖动设置行或顶部图标即可调整顺序。设置行同时提供上移、下移按钮。拖动顶部图标只调整顺序，点击图标切换页面。隐藏当前页签时显示剩余顺序中的首个页签。全部隐藏时展示开启模块的入口，设置入口保持可达。

导航显示与顺序保存至原型浏览器存储，刷新后恢复。v002 的界面状态使用 `cp.h5-v003.*` 键。

## 悬浮终端

第二栏终端实际展开的条件为当前页签是工作空间，且 `settings.terminal` 为真。其它页面及终端收起时展示同一个悬浮终端，页签切换延续其位置、尺寸、最小化状态和当前会话输入。

- 拖动标题栏移动浮窗。最小化后拖动图标移动位置，点击图标恢复浮窗。
- 右下角与左上角拖柄可连续缩放。聚焦拖柄后通过方向键每次调整 20 像素。
- 常规最小尺寸为 280 × 180。宽度达到 520 且高度达到 330 时显示终端演示内容。窄窗口按可用视口尺寸调整显示阈值。
- 标题栏提供展开 / 收起终端内容按钮，以及最小化为图标和在工作空间展开终端按钮。
- 浮窗上限与位置约束按浏览器视口计算，底部预留批注入口空间。
- 从浮窗恢复第二栏时打开工作空间的会话视图。工作空间页签被隐藏时，此操作同时开启该页签。

浮窗和第二栏共享演示终端内容。输入通过当前原型的 mock 桥接发送，发送后的文本显示于当前会话的演示输出中。演示输出保存在本次页面会话内。TAPD 与 Work 的示例条目在页面上标注为演示数据。

## 验证

本版通过 Vite 构建。四处被标注区域在浏览器 DOM 中的匹配数均为 0。桌宠的动作、设置、素材和原生接入规划见 [桌宠开发说明](DESKTOP_PET.md)。浏览器已验证 TAPD 项目与任务切换、Work 分类过滤、Git 工作台操作栏切换、设置行和顶部图标指针拖拽排序、显示开关、全部隐藏后重新开启、顺序刷新保留、浮窗拖动、连续缩放跨越阈值、输入出现在演示输出、最小化后跨模块展示，以及第二栏展开与浮窗展示的联动。

会话第一栏补充调整已在浏览器验证。项目/会话树、额度区和底部操作展示通过。切换会话前后的第一栏文字与滚动位置一致，第二栏显示所选会话。

## Clawd 桌宠

`src/shell/DesktopPet.jsx` 与 `desktop-pet.css` 实现角色、状态气泡、菜单、设置和桌面模式。`App.jsx` 连接当前会话、悬浮输入与窗口演示，设置页提供桌宠配置。9 个 GIF 原文件及 SHA-256 来源记录保存在 `src/assets/clawd/`。具体状态、行为、浏览器验证记录与原生接入设计见 [DESKTOP_PET.md](DESKTOP_PET.md)。
