# 浏览器批注

来源为用户对 H5 v001 的浏览器批注及后续补充。页面为 `http://127.0.0.1:5199/?settings=updates`，批注截图的视口为 1170 × 820。

## 批注 1

目标为 `header.titlebar`，位置为 (220, 29)。

> 点击上面的四个table之后 把一二栏直接进行替换第一栏显示大的一些操作比如，会话目录额度模块；tapd的话第一栏显示各个tapd项目第二栏时tapd任务项以此类推；四个table 可以在设置里面控制是否要展示并且也可以自定义拖拽四个图标顺序

## 批注 2

目标为 `section.floating-composer`，位置为 (355, 538)。

> 这个悬浮框可以自由缩放缩放到一定程度可以显示出终端输入的内容，最小化的话是小的图标 只要是第二栏终端没展开那这个浮窗可以一直存在
