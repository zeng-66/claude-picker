# 桌面发行与版本更新 H5 原型

当前版本为 [v001](v001/index.html)，创建于 2026-11-17。完整前端快照保存在 `v001/src`，来源为当前 App 的 React 界面，包括当时工作区内尚未提交的界面修改。基线提交和源文件 SHA-256 见 [SOURCE.json](v001/SOURCE.json)。

## 启动与批注

在项目根目录运行以下命令。

```bash
./scripts/preview-desktop-prototype.sh
```

浏览器打开 <http://127.0.0.1:5199/?settings=updates>，进入设置里的版本更新页。关闭设置后可浏览项目侧栏、会话、Git、Work、TAPD 和原有设置页面。

点击右下角「H5 v001 · 批注」，填写页面或控件及修改意见。批注保存在当前浏览器，可以导出 JSON。导出的文件放进 `v001/comments/` 后可随代码提交。演示数据和更新状态均在原型内模拟。

更新页的「原型场景」可选择 Windows x64 或 macOS Apple Silicon，并演示有新版本、已是最新、main 尚未发布安装包及网络失败。检查更新、下载、退出安装均有独立状态。

## 后续版本

本目录保留原型及批注，便于逐版比较。下一次界面修改新建 `v002/`，保留 `v001/`，在本文件更新当前版本，并在 [CHANGELOG.md](CHANGELOG.md) 记录来源提交、修改点、批注文件和验收结果。每个版本的 `SOURCE.json` 记录其来源。原型使用自己的快照，后续修改 App 前端时原型保持可复现。
