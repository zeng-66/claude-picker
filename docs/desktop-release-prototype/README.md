## 启动与批注

在项目根目录运行以下命令。

```bash
./docs/desktop-release-prototype/v002/preview.sh
```

浏览器打开 <http://127.0.0.1:5200/>。四个顶部页签切换对应的操作栏与内容区，工作空间采用原项目与会话树。设置中可调整页签显示与顺序。

点击右下角「H5 v002 · 批注」，填写页面或控件及修改意见。批注保存在当前浏览器，可以导出 JSON。导出的文件放进 `v002/comments/` 后可随代码提交。演示数据和更新状态均在原型内模拟。

更新页的「原型场景」可选择 Windows x64 或 macOS Apple Silicon，并演示有新版本、已是最新、main 尚未发布安装包及网络失败。检查更新、下载、退出安装均有独立状态。

## 后续版本
