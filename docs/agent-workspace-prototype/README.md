# Claude Picker · Agent Workspace 交互原型

一次性 H5 设计原型，探索现有桌面外壳与图形聊天、持久任务、TAPD 的组合方式。保留现有原型目录，不修改 Swift 应用。

## 启动

需要 Node.js 18+（建议 22 LTS）：

```sh
cd /Users/zcl/project/claude-picker/docs/agent-workspace-prototype
npm ci
npm run dev
```

打开 http://127.0.0.1:5198/ 。构建：`npm run build`；预览构建：`npm run preview`（先停止开发服务器，避免端口占用）。

## 三种布局

- `/?variant=A` 工作空间：项目/会话树 + 图形聊天 + 任务上下文，适合日常开发。
- `/?variant=B` 任务看板：按排队、执行、待回答、待审阅分组，适合多个任务并行推进。
- `/?variant=C` 专注对话：收起右侧详情、居中会话，适合阅读与讨论。

底部设计切换条不属于正式产品界面。也可用左右方向键切换（输入时不拦截）；URL 保留布局，其他状态只在内存里。刷新重置演示。

## 可体验流程

1. 点击顶部「TAPD 待办」，切换项目或搜索编号，查看需求详情；「创建开发任务」可选择仓库并创建演示任务。
2. 在初始「订单批量锁定与解锁」会话中，选择同步失败策略并「确认并继续」；5 秒后进入待审阅。
3. 进入「变更」，查看模拟 diff，暂存及创建演示提交；确认变更后预览 TAPD 回填，可编辑评论并模拟确认。
4. 在输入框留下草稿，切换会话或布局再返回；收起对话后会出现可拖动输入卡片，恢复时保留草稿。
5. 设置中可查看 TAPD 仓库映射、MCP 服务，以及界面字号和原生终端回退入口的设计。

辅助交互包括新建本地任务/会话、项目展开/收起、模型与模式选择、详情标签、详情栏拖宽和全局搜索（⌘K）。模拟消息用 ⌘Enter 或发送按钮提交。

## 数据与边界

所有需求编号、标题、状态、代码、验证结果、提交和回填均为演示。没有调用 TAPD、Claude、Git 或 MCP，也不读写真实项目文件、认证信息。部分外围配置只展示设计，不应用到系统；没有后端并发调度器。

TAPD 业务状态与 AI 执行状态分别展示。AI 任务完成不表示需求已验收、部署或上线。不填写推断工时或排期。不同任务的输入草稿、审阅与提交演示状态相互隔离。

设计问题：用户能否在熟悉的项目/会话树中，由 TAPD 需求启动任务，在图形会话中回答问题，再审阅并回填？当前原型用于收集反馈，尚未选定最终布局。
