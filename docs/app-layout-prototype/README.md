# ClaudePicker H5 界面原型

用于确认桌面 App 的样式、排版与交互，包含项目与会话、终端输入、可拖动浮窗与浮标、Git 工作台、文件预览编辑、上下文占用展示、设置和 MCP 服务管理。

所有对话、Git 操作、文件编辑、上下文数值和 MCP 服务状态均使用浏览器内演示数据，刷新页面后恢复初始状态。

## 开发预览

使用 Node.js 20 或 22，在本目录运行以下命令。

```bash
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:5188/>。

## 构建

```bash
npm run build
npm run preview
```

终端会打印静态预览地址。构建产物位于 `dist/`。

## 查看压缩包内的静态预览

交付压缩包包含已构建的 `dist/`。解压后进入本目录，运行以下命令。

```bash
python3 -m http.server 5189 --bind 127.0.0.1 --directory dist
```

浏览器打开 <http://127.0.0.1:5189/>。

## 常用交互

- 侧栏按钮控制项目栏与终端展开，项目及会话支持右键菜单。
- 第二栏收起后出现输入浮窗，可拖动、缩为图标浮标、点击展开或恢复第二栏。
- 输入区点击当前值选择模式、模型和推理强度，闪电切换快速模式，彩色环悬停显示上下文占用。
- 分支入口包含项目与分支双栏，双击分支或按回车签出，右键打开分支操作。
- 变更栏可收起，右侧分隔条调整宽度，内部两条横向分隔条调整三个区域的高度。文件列表独立滚动。
- 设置页包含界面字号、终端字号、会话分支跟随、布局选项与 MCP 服务管理入口。

## 文件

- `main.jsx` 包含界面与演示交互。
- `style.css` 包含样式与布局。
- `clawd-mark.png` 为原 App 标识。
- `vite.config.mjs` 包含独立预览与构建配置。
